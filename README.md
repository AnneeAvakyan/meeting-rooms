# Переговорка — сервис бронирования переговорных комнат

Веб-сервис на Go для управления бронированием переговорных комнат: просмотр доступности, создание/изменение/отмена броней, контроль пересечений по времени, отчёты по использованию.

## Функциональность

- Список переговорных комнат и их параметров (вместимость, оборудование)
- Создание, изменение и отмена бронирований
- Проверка пересечения временных интервалов при бронировании
- Календарь занятости переговорной
- Поиск свободных переговорных на заданный интервал
- Хранение пользователей и броней
- Отчёты по использованию помещений (с возможностью экспорта в CSV/Excel)
- (Доп.) Авторизация, роли (сотрудник/администратор), уведомления, интеграция с календарём

## Технологический стек

- **Язык:** Go
- **HTTP:** net/http + `chi` (или `gin`/`echo` — выбрать один)
- **БД:** PostgreSQL (prod), SQLite (для локальной разработки/тестов)
- **Доступ к БД:** `sqlx` или `pgx`, миграции через `goose`/`golang-migrate`
- **Конфигурация:** переменные окружения (`.env` + `viper`/`envconfig`)
- **Контейнеризация:** Docker, docker-compose (приложение + Postgres)
- **Тестирование:** стандартный `testing`, `testify`
- **Документация API:** OpenAPI/Swagger (`swaggo`)

## Запуск

```bash
cp .env.example .env
docker-compose up --build
```

API будет доступен на `http://localhost:8080`.

## Основные сущности

- **User** — id, имя, email, роль
- **Room** — id, название, вместимость, оборудование
- **Booking** — id, room_id, user_id, start_time, end_time, status, created_at

## API (черновой список эндпоинтов)

| Метод | Путь | Описание |
|---|---|---|
| GET | /rooms | список переговорных |
| GET | /rooms/available?from=&to= | поиск свободных комнат |
| POST | /bookings | создать бронирование |
| PUT | /bookings/{id} | изменить бронирование |
| DELETE | /bookings/{id} | отменить бронирование |
| GET | /rooms/{id}/calendar | календарь занятости комнаты |
| GET | /reports/usage | отчёт по использованию |
